# 安心闹钟 2.1.1

Android 原生 Java 应用，compileSdk / targetSdk 36，minSdk 26。包名、签名均沿用 1.0，可以覆盖安装；首次启动迁移旧录音和未来闹钟。

## 功能

- 多个独立闹钟、名称、开关、编辑和删除；各自选择本机录音，可复用其他闹钟已导入的录音。
- 滚轮选择小时与分钟。重复日期支持仅一次、每天、中国大陆法定工作日、休息日、自定义星期和指定多个日期。
- 「录音播放一遍」与「循环播放指定时长」可自由切换。循环可精确到秒，上限 180 分钟。
- 贪睡重播可设置开始间隔和额外重播次数（0–100）。响 2 分钟、间隔 5 分钟时，安静 3 分钟后再响；额外重播 2 次表示含首次共 3 次。间隔必须大于当前播放时长。
- 响铃时提供悬浮卡片、通知及锁屏响铃页，均可用 × 结束本轮全部剩余重播，保留后续日期的计划。
- 30 秒后试响不替换原日期，试响不执行额外重播，结束后自动删除测试条目。

## 后台与冲突处理

使用 AlarmManager.setAlarmClock 为每个闹钟分别安排下一个日期和下一次有限重播。等待时没有常驻服务或轮询；重播之间只保留普通可关闭通知。播放期间才使用 mediaPlayback 前台服务、MediaPlayer 唤醒锁、音频焦点。

多闹钟恰好同时到达时，服务依次播放，避免音频混在一起；每个闹钟的重播间隔从其实际开始播放计算。相同闹钟的下一日期到来时，上一日期尚未完成的重播让位于新日期。播放错误、音频焦点丢失不继续重播。不能承诺在关机、强行停止、应用冻结、厂商禁止后台或系统进程终止后仍然响铃。

重启并解锁后重排未来日期；未来的已安排重播可恢复，已过期的声音不补播。系统时间或时区改变时结束原本轮重播，按新本地时间重排日期。应用被杀死后的当前录音不从头重放。

## 节假日

内置 2026 年中国大陆国务院公布的完整放假、补班日期；普通日期按周一至周五工作。工作日模式在周末补班日响、放假日不响，休息日模式相反；「每天」和「每周自定义」独立于法定日历。

官方依据：https://www.gov.cn/zhengce/content/202511/content_7047090.htm

在首页「安心响铃 → 调休日历」可选择年度联网更新并缓存，也保留年度 JSON 导入。联网数据源为 NateScarlet/holiday-cn 开源数据（引用正式放假安排），获取失败保留原有日历。未知年度不会默认为周一至周五，而会暂停该年度工作日/休息日安排，并在闹钟卡片提示日历待更新。仅在点击更新时联网，不申请读取手机日程的权限，不内置尚未核实的未来安排。

格式：

```json
{
  "year": 2026,
  "days": [
    { "date": "2026-01-01", "isOffDay": true },
    { "date": "2026-01-04", "isOffDay": false }
  ]
}
```

此代码段仅演示字段，不能作为完整年度日历导入。`isOffDay=true` 为放假，`false` 为补班；文件应列出全年全部放假和补班日期。导入限制 1 MB、同年度、无重复日期、严格布尔字段；应用无法自动核验文件是否遗漏某个节假日，请使用可信来源并核对。

## 权限与流体云

Android 13+ 使用闹钟用途的 USE_EXACT_ALARM；Android 12 / 12L 使用 SCHEDULE_EXACT_ALARM 并检查授权。POST_NOTIFICATIONS 用于播放、等待和结束按钮；SYSTEM_ALERT_WINDOW 仅用于响铃时的悬浮卡片；USE_FULL_SCREEN_INTENT 用于锁屏响铃页，可在首页设置中开启。后台播放类型为 mediaPlayback。

悬浮卡片是本应用自己的提醒窗口，并非厂商流体云。OPPO 真正流体云的部分展示行为需要厂商配置，未集成相关私有 SDK。全屏/悬浮展示受 Android 和 ColorOS 权限、系统状态控制。

## 构建和签名

需要 JDK 17、Android build-tools 36.0.0、platforms/android-36。无需 Gradle 或第三方运行库：

```powershell
.\build.ps1 -Jdk 'C:\tools\jdk-17' -BuildTools 'C:\tools\android\build-tools\36.0.0' -Platform 'C:\tools\android\platforms\android-36'
```

构建顺序为 aapt2 → javac --release 8 → D8 → zipalign → apksigner。`.signing/release.p12` 是本应用的本地签名密钥；口令在构建脚本内。请私下保管，覆盖升级需使用同一签名。测试代码不打入 APK。
